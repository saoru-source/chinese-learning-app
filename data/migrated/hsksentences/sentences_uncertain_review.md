## HSKsentences(例文データ、2026-08-22)文法ポイント再分類

### 背景
`words_uncertain_review.md`のHSKsentencesの項目で報告した通り、元データの
文法ラベル(g列)は実際の例文内容とほとんど一致していませんでした
(1,947件中およそ97%が不一致と推定)。そこで、各例文の漢字本文を実際に
判定し、70件のgrammar_pointsのどれに該当するか(該当なしも含め)を
再判定しました。

### 判定方法(重要・前提として共有)
1,947件を1件ずつ目視で読んで判定するのではなく、70件それぞれの文法
ポイントについて「その文法が使われていれば必ず現れる特徴的な言い回し」
(例:把構文なら「把」、只要～就～なら「只要…就」の共起、受身形なら「被」等)
を、Claudeの中国語文法知識に基づいてパターン化し、それを1,947件全件に
機械的に適用する方式を取りました。理由は以下の通りです。
- 「了」「是」「的」「都」「也」のようなごく一般的な助詞・副詞は、
  ほぼ全文に出現するため単独では判定材料にならず、パターン化しないと
  逆に精度が落ちる
- 1,947件を毎回ゼロから個別に読解判定するより、明確なルールとして
  適用する方が、同じ基準を全件に一貫して適用でき、再現性・検証可能性が
  高い
- 実際にルール作成の過程で2件のバグ(例:「妹妹」等の家族呼称を動詞の
  重ね型と誤判定、「可惜」を文法ポイント「于是／可」と誤判定)を発見し、
  都度ルールを修正した上で再実行している

### 全体結果
| 判定区分 | 件数 | 説明 |
|---|---|---|
| confident(確信度高) | 180件 | 元の例文と同じHSKレベルの文法ポイントの中で、他候補と重複せず一意に該当 |
| tie(複数候補が同点) | 1件 | 同レベル内で複数の文法ポイントに同程度該当。要確認 |
| other_level(レベル不一致) | 530件 | 例文自身のHSKレベルと異なるレベルの文法ポイントに該当。文法自体は妥当な可能性が高いが、レベル分類のズレとして要確認 |
| no_match(該当なし) | 1,236件 | 70件のどの文法ポイントにも、明確な特徴パターンが見つからなかった |

該当なし(no_match)の1,236件は、文法ドリル用の例文としては使えませんが、
拼音・和訳自体は正確なため、読解・リスニング練習用の一般例文としては
引き続き使えます。全件のリストは`data/migrated/hsksentences/sentences_no_match.json`
に保存済みです(レベル内訳: 1級124件、2級263件、3級226件、4級621件)。

### tie(同点)の内容
| 例文 | 候補 |
|---|---|
| 他们又吵又吵架，声音越来越大。 | 還是と或者／又～又～／越来越～ 、 越A越B／A跟B一样 |

「又～又～」と「越来越～」の両方が同じ文に含まれており、どちらの文法
ポイントの例としても成立するため、機械的に前者を採用しましたが、
実際にどちらの練習に使うかは要判断です。

### other_level(レベル不一致)の代表例
| 例文 | 例文自身のレベル | 該当した文法ポイント(レベル) |
|---|---|---|
| 车在车站上。 | 1級 | 在～上(4級) |
| 这个比那个贵。 | 1級 | 比較構文(1) 比(2級) |
| 别的人不是病人。 | 1級 | (誤判定→修正済み。現在はno_match) |

「文法自体は正しく使われているが、例文が想定より簡単な単語で作られて
いるため、元々のレベル分類より低いレベルの例文になっている」ケースが
多いようです。逆に言うと、**例文のHSKレベル自体も、文法ポイントの
レベルほど厳密ではない可能性がある**という発見です。530件全件のリストは
`data/migrated/hsksentences/sentences_ties_and_mismatches.json`に
保存済みです。

## HSKsentences(例文データ、2026-08-22)レベル表記の修正(other_level 530件の処理)

上記のother_level(530件)について、「grammar_point自体の紐づけは正しい」
という前提で、grammar_points.json側のhsk_levelをsentenceのhsk_levelへ
上書きする作業を行いました。作業前に、530件全件についてどのパターンが
根拠で該当と判定されたかを再確認し、根拠が弱い・文自体が不自然なものを
洗い出したところ、以下の**41件**が見つかったため、これらは上書きせず
保留(元のhsk_levelのまま)としました。

### 保留にした理由の内訳

**(1) 「也」1文字だけが根拠(23件)** — grammar_point「是／也／都／是吧」
「也」は非常に汎用的な副詞で、この1文字だけでは「是／也／都／是吧」の
例として確信を持てません。また、この23件の中には文自体が破綻している
ものも混ざっていました(例:「但是蛋不但但也当时吃了。」「我懂，也懂得
动物动物园。」)。

**(2) 「就〜了」が連続動作とは言い難い(2件)** — grammar_point「補語 来去／就（連続動作）」
- 如果下雨，就不去了。 → 「就」はここでは条件文の帰結を表しており、
  連続動作(すぐに〜する)の用法ではない
- 早晨我吃早餐，早就吃完了。 → 「早就」は「とっくに」という固定表現で、
  連続動作の「就」とは別の用法

**(3) 文自体が破綻・意味不明(4件)**
- 才看菜单，才参观。 → grammar_point「比較 A比B多一些／才と就」。「才」が
  たまたま2回出現しているだけで、文として意味が通らない
- 得出的话得说清楚。 → grammar_point「应该／得(děi)」。文の構造が不自然
- 国际过来过年了。 → grammar_point「補語 来去／就（連続動作）」。
  「过来」という語自体はマッチしているが、文全体が意味不明
- 进来，别进去了。 → grammar_point「補語 来去／就（連続動作）」。
  「进来(入ってくる)」と「进去(入っていく)」が矛盾する内容で並んでおり不自然

**(4) 「比」を含む別の単語と混同(12件)** — grammar_point「比較構文(1) 比」
「比較(比較的)」「比赛(試合)」という、比較構文の「比」とは無関係な単語に
含まれる「比」の字を拾ってしまっていました。以下はすべて「比較構文」の
例文としては不適切です。
| 例文 |
|---|
| 这场比赛，胜利的比例比较高。 |
| 教练比较严格，教材也叫他好好学。 |
| 我已经报名了汉语比赛。 |
| 这个问题比较复杂。 |
| 我们一起观看了足球比赛。 |
| 她获得了比赛的金牌。 |
| 这座城市将举办马拉松比赛。 |
| 在北方，荔枝比较少见。 |
| 他在比赛中受伤了。 |
| 我们球队昨天输了比赛。 |
| 这个问题比较严重。 |
| 最后我们赢了这场比赛。 |

なお、同じ「比較構文(1) 比」に分類された530件中の残り4件
(「这个比那个贵。」「这个菜比那个差。」「你的年龄看起来比实际小。」
「今天比昨天暖和多了。」)は、実際に「A比B」の比較構文が使われている
正しい例文のため、レベル修正を適用済みです。

### 結果件数
- 対象(other_level): 530件
- レベルを修正した件数: **489件**
- 保留(uncertain_reviewに回した)件数: **41件**(上記内訳の合計)

保留にした41件は、`sentences.json`のhsk_levelを変更せず元のままにして
あります。grammar_point_label_matchedの紐づけ自体も残していますが、
上記の理由により信頼度が低いため、ネイティブチェック時にこの41件を
優先的に見直すことをお勧めします。

### 副次的な発見(今回のタスクの範囲外・参考情報)
作業中、上記以外にも「建设并建成了它」「推动并推进了这项计划的推广」
「现代…现场…现金…现实」のように、同じ漢字を無理に繰り返して作られた、
不自然な例文がいくつか見つかりました。これらは文法ポイントの紐づけ自体は
誤っていない(該当する文法は実際に使われている)ため今回は修正対象外
としましたが、例文としての品質(自然さ)には別途課題がありそうです。

### この方式の限界(正直な申告)
- パターンマッチングによる判定のため、慣用句や特殊な言い回しで文法要素が
  暗示的にしか現れない例文は、実際にはその文法を使っていても
  no_match(該当なし)に分類されている可能性があります
- 逆に、たまたま特徴的なキーワードが別の意味で出現し、誤って該当ありと
  判定してしまっている(誤検出)ケースが、発見した2件以外にも残っている
  可能性があります
- 「動詞の重ね型／結果補語 懂好完见错／从～」のように、1つのラベルに
  複数の異なる文法現象が混在しているものは、判定の粒度が粗くなりがちです
- 上記の理由により、especially「confident」「other_level」と判定された
  711件(180+1+530)についても、ネイティブによる最終確認を推奨します
