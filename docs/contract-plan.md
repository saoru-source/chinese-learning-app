# 契約・料金プラン

現在は無料枠のみで開発を進める。商用化（課金機能追加/広告掲載/
正式リリース）のタイミングで以下を有料化する。

### 今（開発中）: 無料のまま
- Vercel: Hobby（無料、非商用のみ）
- Supabase: Free（MAU 5万人まで無料）
- Claude API: 未契約。AI出題機能の実装・テスト開始時のみ少額課金発生

### 商用化の直前に切り替えが必須なもの
- **Vercel: Hobby → Pro（$20/月）**
  Hobbyは規約上、商用利用不可。これだけは商用化前に必ず切り替える
- **Claude API契約**（AI出題機能を本番稼働させる場合）
- **法務書類の整備**（お金はかからないが必須）
  - プライバシーポリシー（ログイン機能を作る前に用意）
  - 利用規約
  - 特定商取引法に基づく表記（課金機能がある場合のみ）
- **Stripe等の決済サービス**（課金機能を作る場合のみ）

### ユーザー増加に応じて検討
- Supabase: Free → Pro（$25/月）
  MAU 5万人 or DB 500MB超えが近づいたら移行を検討

### 判断の優先順位
Vercelの商用利用制限が最も厳格なので、他のサービスより先に
対応する。Supabaseは無料枠のまま商用スタートしても規約上問題ない。
